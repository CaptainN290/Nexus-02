⛊ Moderation

  • n/kick @user <reason> — Kick a member.
  • n/ban @user <reason> — Ban a member.
  • n/unban <user_id> — Unban a user.
  • n/timeout @user <minutes> <reason> — Timeout a member.
  • n/removetimeout @user — Remove a timeout.
  • n/mute @user <reason> — Mute a member.
  • n/unmute @user — Unmute a member.
  • n/warn @user <reason> — Warn a member.
  • n/snipe [0-5] [#channel] — Retrieve deleted messages.
  • n/clear <amount> — Delete a number of messages.
  • n/setupapp #channel <title> - <questions> — Setup a form sent to a channel.
  • n/openapp [@user] — Apply for a role or membership.

⚙︎ Channel

  • n/slowmode <seconds> — Set channel slowmode delay.
  • n/lock — Lock the channel.
  • n/unlock — Unlock the channel.

𐀪 Roles

  • n/addrole @user @role — Give a member a role.
  • n/removerole @user @role — Remove a role from a member.
  • n/rolecatalog — View all roles (limit: 20).

𝒊 Info

  • n/userinfo @user — View info about a user.
  • n/serverinfo — View server info.
  • n/serverbanner — Show the server banner.
  • n/avatar @user — View a user’s avatar.
  • n/ping — Check bot latency.
  • n/time — Display current UTC time.
  • n/status — Show bot and web status.
  • n/invite — Get the bot’s invite link.
